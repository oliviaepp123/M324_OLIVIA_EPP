# 11e – Choose one

## Task: My app needs a database. How could I do that?

GitHub Pages only hosts static files (HTML, CSS, JS). It has no server and no database.
So the database must run somewhere else.

**Options:**

1. **Firebase or Supabase:** The website talks to an online database with JavaScript. No own server needed.
2. **Own backend with an API:** A server (e.g. Node.js + PostgreSQL in Docker) stores the data. The website gets the data with `fetch()`.
3. **localStorage:** Saves data in the browser. Only works on one device, not shared.

**My choice:** Supabase or Firebase, because it is simple and works well with a static website.
